# Ícones do PWA

Coloque aqui os ícones reais da marca (a partir do logo "Disk Pizza Rozeno"):

- `icon-192.png` — 192×192
- `icon-512.png` — 512×512
- `icon-maskable-512.png` — 512×512 com margem de segurança para máscara adaptativa (Android)

Recomenda-se exportar em fundo sólido `#953C2A` (cor primária "Brasa") ou `#FAF8F5` (papel),
sempre com o símbolo centralizado e respiro de ~15% nas bordas para a versão maskable.
